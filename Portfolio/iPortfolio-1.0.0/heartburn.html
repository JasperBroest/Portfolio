Heartburn

  • Category: Virtual Reality
  • Project date: 06 May, 2025
  • Time: 8 weeks
  • Made with: Unity, C#, MetaXR SDK

Don't stop moving!

In this game you have to keep moving to stay alive. While doing that you also have to avoid the enemies that are flying toward you. After you've defeated a wave you can choose an upgrade. The goal is to survive as long as possible.

You can use your rocket arms to fly around in the map, and dodge the enemies. This allows you to do some really cool tricks.

I mainly focused on making the enemies is this project. I also made the main menu and in-game menu. However I fixed a lot of bugs and helped my team a lot. I led the stand-ups every day and I did the sprint plannings. I also led the retrospectives and I made sure that everyone was on the same page.

Flying Enemies

I'm most proud of the flying enemies. I use a steering behavior to navigate them around the map without any Unity Nav-Mesh. They will try to avoid each other and obstacles, while also trying to get to the player. This makes them very dynamic and unpredictable. They also have movement prediction and a dash when they get close to the player. I made 3 different variants: fast/weak, normal, and slow/tank.

Player Detection

For the player detection I use the OverlapSphere function to see if the player is in range. If so I send a raycast to the player's position to see if its in line of sight.

Enemy steering

This is the main code for the steering behavior. It calculates the desired velocity based on the player's position and the enemy's current position. This makes it move towards the player.

Obstacle Avoidance

This function will calculate the 'best' avoidance direction. It uses the RaysOnPlane function to calculate this for each of the planes (XZ, YZ, XY).

Obstacle Detection

In this function I sent out rays around the enemy on a given plane. If it detects an obstacle it will calculate how much it weights based on the distance to the obstacle. If not it adds the direction of the ray times its weight to the total.
